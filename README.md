# Meridian Capital — Financial Services Web Portfolio

An original WordPress theme by KnowEdge Business Development Services Ltd, built around a midnight navy, platinum and gold visual identity. It includes an illustrative market snapshot, interactive compound growth calculator, educational insights, responsive navigation, accessible FAQs and a website consultation enquiry builder.

## Live website

[Explore Meridian Capital](https://meridiancapital-knowedge.infinityfree.io/)

[![Meridian Capital homepage](https://raw.githubusercontent.com/Kelvinkingly/Kelvinkingly/main/assets/meridian-capital-homepage.jpg)](https://meridiancapital-knowedge.infinityfree.io/)

## Install
Zip the `theme/meridian-capital` directory; in WordPress, open Appearance → Themes → Add Theme → Upload Theme, upload the ZIP and activate.

## Limitations
This is an independent portfolio project, not an investment provider. Market figures are illustrative, future returns are not assured, and the growth calculator excludes taxes, fees and inflation. The consultation builder prepares an email link and does not submit personal information or bookings. No deposits, payment processing or investment transactions are implemented.
